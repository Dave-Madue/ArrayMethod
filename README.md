# ArrayMethod

This code snippet demonstrates common JavaScript Array Methods used to manipulate and retrieve data from an array of objects.

# Key Operations
- Chaining filter() and map(): It filters the users array to find individuals older than 18 and then creates a new array containing only their names.

- The map() Method: It extracts all names from the list into a simple string array.

- The find() Method: It searches the array for a specific user object based on a unique id.

- Control Flow: It uses a for...of loop with a conditional check to identify the first "adult" in the list and log a message.

# Technical Summary
The script showcases functional programming patterns in JavaScript, focusing on data transformation and array iteration. It is a practical example of how to handle JSON-like data structures efficiently.
